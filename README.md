# Smart Event Management & Ticketing Platform

Developed by Group R

---

## Project Overview

The Smart Event Management & Ticketing Platform is a web-based application developed using Node.js, Express.js, MongoDB, and EJS following the MVC architecture pattern.

Users can:
- Browse and search events
- Book tickets
- Submit enquiries

Administrators can:
- Create and manage events
- Monitor bookings
- View dashboard analytics

---

## Features

### User Features
- User registration and login
- Browse and search events
- Book tickets
- Submit enquiries

### Admin Features
- Full CRUD operations on events
- Manage bookings
- Dashboard analytics
- Capacity validation

## Setup Instructions

### Clone Repository

```bash
git clone https://github.com/RyanTPH/Smart-Event-Platform
```

### Navigate to Project Folder

```bash
cd "WPR381 Project"
```

### Install Dependencies

```bash
npm install
```

### Run the Application

Development Mode:

```bash
npm run dev
```

Production Mode:

```bash
npm start
```
